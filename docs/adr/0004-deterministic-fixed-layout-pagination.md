# Deterministic Fixed-Layout Pagination with Mobile Camera Focus

Every volume uses a fixed classic page aspect ratio and deterministic pagination (identical page breaks across all devices), rather than dynamically reflowing text for different viewport sizes. On narrow mobile portrait screens, the 3D camera focuses cleanly on one page of the open spread at a time.

## Consequences

- Page numbers, chapter start pages, book thickness, and saved bookmarks remain identical across desktop and mobile.
- Readers cannot dynamically resize the underlying font layout; zooming is handled by moving the 3D camera closer to the page.
