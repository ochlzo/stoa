# Data-Driven Parametric Volume Kit Over Bespoke Book Meshes

Every `Volume` in the `Catalog`—both `Readable Volumes` (starting with *The Odyssey*) and `Placeholder Volumes`—is generated by a single data-driven parametric `Volume` kit configured by dimensions and `Binding Style` presets, rather than building bespoke one-off 3D geometry per title.

## Considered Options

- **Single parametric `Volume` kit with capability flags (chosen)**: Adding a future `Readable Volume` requires only a `Catalog` entry and literary content, with zero new 3D modeling. `Readable Volumes` automatically enable interactive geometry (such as a `Bookmark Ribbon`, openable covers, and turning `Leaves`) while `Placeholder Volumes` stay lightweight closed silhouettes.
- **Bespoke hero geometry per readable book**: Allows completely custom sculptures per title, but creates linear 3D maintenance work for every new book added to the library.

## Consequences

- Distinct visual details introduced for *The Odyssey* (such as raised spine bands, headbands, or a `Bookmark Ribbon`) must be implemented as reusable `Binding Style` presets or `Readable Volume` features on the shared kit.
